Abstract

We prove that kk-sparse attention converges to full attention as kk approaches the sequence length, and bound the error for finite kk.

Index Termsattention, sparsity, convergence

Introduction

Attention costs O(n2)O(n^2) in the sequence length nn [1]. Keeping the top kk scores per query reduces this to O(nk)O(nk), a rule that has worked well in practice1 but has lacked a simple analysis.

A short implementation fits in a few lines:

def sparsify(scores, k):
    top, index = scores.topk(k, dim=-1)
    return top.softmax(dim=-1), index

Conclusion

Sparse attention is safe whenever the discarded mass is small, which is the common case. Peaked distributions benefit the most.
